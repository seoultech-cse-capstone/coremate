## 목업과 실제 화면이 다른 곳

목업을 그대로 스펙으로 읽으면 안 되는 부분이다.

- **틀린 문제의 OMR 4지선다** — 넣지 않았다. 응답에 선지 전체 목록이 없어서 내 답과 정답
  두 칸만 그리면 답안지로 읽히지 않는다. 대신 두 선지의 문장을 그대로 보여 준다.
- **착각별로 묶은 틀린 문제 목록** — 실제로는 묶지 않고 평평한 목록에 오개념 제목을 태그로 단다.
