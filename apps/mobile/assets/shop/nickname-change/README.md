# 닉네임 변경권 에셋

이 폴더에 닉네임 변경권 이미지를 넣어주세요.
코드에서는 `require("../../../assets/shop/nickname-change/<파일명>")` 로 참조합니다.

## 넣을 파일 (권장 명명)

| 용도 | 파일명(예시) | 형식 |
|---|---|---|
| 기본 이미지 | `ticket.png` | PNG (투명 배경 권장) |
| 저해상도(선택) | `ticket_1x.png` | PNG |

- 지금 상점 카드는 `Sparkles` 아이콘을 쓰는데, 이미지를 넣어주시면 그 자리에 교체합니다.
- 파일명이 위와 달라도 됩니다 — 실제 넣어주신 파일명 그대로 연결합니다.
- 실제 파일을 넣은 뒤 이 README 는 지워도 됩니다.
