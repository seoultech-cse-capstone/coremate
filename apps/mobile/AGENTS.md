# CoreMate Mobile Agent Guide

## Scope

- Work only inside `apps/mobile`.
- Do not edit `backend`, `be`, `ai`, or other project directories unless the user explicitly approves it.
- This app is the React Native + Expo + TypeScript frontend for CoreMate.

## User Approval Rules

- Reading files and inspecting project structure is allowed without asking.
- Before running CLI commands, ask the user for confirmation.
- Before creating, editing, deleting, or moving files, explain the intended change and ask for confirmation.
- Do not run destructive commands such as `git reset`, `git checkout --`, or recursive deletes unless the user explicitly requests them.

## Tech Stack

- Use Expo, React Native, TypeScript, and Expo Router.
- Use npm as the package manager.
- Prefer the dependencies generated by `create-expo-app`.
- Do not add NativeWind, Zustand, TanStack Query, or UI libraries unless the user approves it.

## Mobile App Structure

- Keep routing under `app/`.
- Keep shared frontend code under `src/shared`.
- Keep feature code under `src/features`.
- Maintain the Weakness tab flow:
  - `app/(tabs)/weakness/index.tsx`
  - `app/(tabs)/weakness/[sessionId].tsx`
- Weakness detail screens should remain inside the tab navigator so the bottom tab bar stays visible.

## UI Guidelines

- Use basic React Native components.
- Use `StyleSheet` for styling.
- Prioritize clear MVP screens over decorative UI.
- Avoid connecting screens to real APIs until the API contract is ready.

## API

- Use `EXPO_PUBLIC_API_BASE_URL` for backend API base URL.
- Keep API client code in `src/shared/api/httpClient.ts`.
